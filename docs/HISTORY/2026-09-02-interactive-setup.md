# Historical: Interactive TUI Setup

This document preserves the former `coding-agent-ai` interactive setup/TUI documentation. Setup functionality was separated into the `agent-setup` control plane.

The historical document described a five-step builder for selecting coding agents, FlossWare AI capabilities, budgets, project directories, and generated configuration files. It also documented the former theme picker and `scripts/setup.py` workflow.

For current installation, profile management, discovery, diagnostics, and external-agent setup, use `FlossWare/agent-setup` instead.
